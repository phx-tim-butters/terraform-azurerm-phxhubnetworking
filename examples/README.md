This folder contains runnable module usage examples.

## Available examples

- [examples/virtual_network_gateway/example.tf](virtual_network_gateway/example.tf)
- [examples/virtual_wan/example.tf](virtual_wan/example.tf)

## Notes

- The example provider blocks include explicit subscription and tenant IDs. Replace these with your own values or remove them to use environment-based authentication.
- Do not commit production secrets in example files.
